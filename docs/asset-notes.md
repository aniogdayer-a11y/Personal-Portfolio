# Asset preparation

The user supplied five photographs of their real José Rizal University lanyard and college ID in chat, and authorized preparing usable assets directly from those references. Original image files were not available in the local attachment directory.

The built-in image-generation **edit** workflow was used for background extraction, perspective correction and clarity improvement. These are AI-cleaned reference-derived assets, not untouched original photo crops. Fine portrait details, artwork and barcode reproduction may differ from the originals; this is a portfolio visual. The school identity, navy/gold palette, portrait layout and supplied printed name were retained.

## Final project files

- `public/assets/jru-id.png`: 1024 × 1536 transparent PNG; cleaned portrait ID with clear holder. Shown at a maximum CSS width of 252px, preserving proportions. The profile now uses the separate formal portrait described in `portrait-preparation.md`.
- `public/assets/jru-strap-source.png`: 1060 × 1484 transparent PNG; straightened navy-and-gold woven ribbon. The SVG renderer maps its central ribbon onto the two attachment segments.
- `public/assets/project-preview.png`: browser screenshot of the implemented desktop intro.

The black buckle, gold lower strap and metal hook are lightweight SVG elements matched to the photographed attachment. They are separate from the ID so the holder and lanyard remain connected during motion.
